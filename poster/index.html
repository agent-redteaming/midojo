Your Agent's Tools Are Its Attack Surface

The problem with current agent red-teaming

  • Tool-using AI agents are vulnerable to prompt injection through many surfaces — not just the user prompt
  • An agent's tools, the data they return, and their descriptions are all attacker-controlled in realistic threat models
  • Current red-teaming tools test one surface at a time in simulated environments — missing how real attacks land
  • Attacks that succeed via tool calls leave no trace in the agent's text output — input/output testing is blind to them

Real-World Attack Vectors

  • MCP Tool Poisoning — hidden directives in tool descriptions (CVE-2025-54136)
  • Indirect Prompt Injection — instructions hidden in data the agent reads (Greshake et al.)
  • Tool Response Manipulation — compromised APIs return malicious content (CyberArk ATPA, 2025)
  • Memory Poisoning — false entries in RAG/memory stores (MINJA, NeurIPS 2025)

Man-in-the-Middle, Not Simulation

MiDojo interposes between the agent and its tools

Swiss-cheese interception: each tool independently forwards to the real backend, intercepts and injects attack payloads, or both. No agent modification required — works with any MCP-compatible agent.

6 Attack Surfaces, One Framework

Every channel a real attacker would use

Surface Channel How the Payload Arrives Access Level
User Prompt user_prompt Injected directly into the user's message Black-box
Environment Data environment_state Hidden in data fields the agent reads (customer notes, transaction descriptions) Gray-box
Tool Descriptions tool_description Hidden directive in MCP tool description metadata Gray-box
Tool Responses tool_output Injected into tool return values at runtime White-box
Memory / RAG memory Poisoned entries in agent's memory store Gray-box
Inter-Agent inter_agent Forged messages between agents in multi-agent systems White-box
MiDojo grades utility (did the agent complete its task?) and security (did the attack cause an unauthorized tool call?) together — catching attacks that leave no trace in the output.

Strategies

  • Static — one-shot payload delivery
  • PAIR — iterative adversarial refinement (Chao et al., NeurIPS 2023)
  • TAP — tree search with pruning (Mehrotra et al., NeurIPS 2024)
  • Crescendo — progressive multi-turn escalation (Russinovich, USENIX 2025)
  • Multi-phase — compose attacks: poison memory → exploit via prompt

Red-Team Your Agent in 3 Commands

No agent modification required. Works with any MCP-compatible agent.

# 1. Start MiDojo control plane + fake MCP server midojo-serve --suite minibank --port 8080 minibank-fake-mcp-serve --port 8082 --upstream-url http://localhost:8081/mcp # 2. Run static attacks across all channels midojo-run --agent-url http://your-agent:8080 --protocol openai --suite minibank # 3. Run adaptive attacks (PAIR with an attacker LLM) midojo-run --agent-url http://your-agent:8080 --protocol openai --suite minibank \ --attacker-model gpt-4o --attacker-api-key $OPENAI_API_KEY
